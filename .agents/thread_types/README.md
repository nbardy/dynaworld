# DynaWorld Thread Types

Evergreen thread types are reusable agent roles with a stable prompt, evidence
collection contract, and optional scheduler.

## Available

- `cto_code_reviewer_super_autist/` - hourly, read-only CTO-quality review of
  recent commits plus staged, unstaged, and untracked disk changes. Generated
  packets and reports are written under ignored `outputs/code_reviews/`.
