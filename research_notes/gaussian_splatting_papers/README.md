# Gaussian Splatting Paper Notes

This folder holds papers whose main relevance is Gaussian-splat rendering,
compositing, visibility, primitive shape, or parameter efficiency. Keep it
separate from:

- `../foam_papers/`, which is PowerFoam-specific.
- `../blur_dof_motion_papers/`, which is a curated blur, DoF, exposure, and
  rolling-shutter corpus.
- `../gauged_uvt_trace_atlas/`, which is DynaWorld's own trace-atlas theory.

## Layout

- `pdfs/` - downloaded PDFs.
- `sources/` - unpacked arXiv source bundles when available.
- `text/` - plain-text extraction from PDF for quick search.
- `media/` - extracted figures produced during Markdown conversion.
- `paper_index.md` - searchable paper list and routing notes.
