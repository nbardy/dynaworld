Main lesson:

ReAct is the minimum viable agent loop: thought, action, observation, repeat.
It has no archive, no evolution, no curriculum, and no skill library. That makes
it the baseline that local `llamea_serial` or CodeEvolve-style loops must beat
on a real microlib.

Important design consequences:

- Add `react_repair_loop`, `candidate_trace_schema`, `loop_detector`,
  `observation_provenance_checker`, and `human_reflection_store` microlibs.
- Store thoughts/reflections for audit and prompt control, but treat evaluator
  artifacts as evidence.
- Detect repeated commands, repeated exceptions, and repeated patch targets.
- Preserve observation provenance so stale logs or partial smokes are not
  treated as current proof.
- Compare one-shot `codex exec`, bounded ReAct repair, and serial evolution on
  the same Codex-call budget before adding islands.
