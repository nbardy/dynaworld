## Interpretation

This is a stability and continuation pass, not a visual-quality promotion. The
RGB-probe media is valid and follows coarse layout, but it remains very blurry
and looks nearly unchanged from the earlier sparse-forward media family. The
current `22.027` probe PSNR is about `1.37 dB` below the standalone target-grid
oracle (`23.401` grid PSNR), but that oracle itself is only `20.073` after
full-video upsampling and is still blurry. The speed path is now good enough for
local single-video iteration; the next quality move should change the
objective/model capacity or feature-to-RGB bridge rather than only spending more
identical 50-step continuations.

Use the 1500-step checkpoint for any next continuation unless the goal is to
reproduce the checkpoint-selection decision.
